Common questions

Does SmoothTalker see my messages?
No. It is a static library your agent downloads. Drafting happens inside the agent. See the privacy policy.

The agent isn't using SmoothTalker.
Ask it directly: "Use the SmoothTalker playbooks for this." Each drafted reply should end with a line like Playbook: apologize. If it doesn't, the skill may not be installed; see the setup prompt.

The advice didn't fit my situation.
Tell the agent what you want ("say no flat", "one version only", "keep it cold"). Your stated intent always overrides the playbook. If a playbook is wrong or missing, open an issue with the situation and we'll add or fix it.

Can I add my own playbooks?
Yes. The repository is public and content is CC BY 4.0. Fork it, add a Markdown file under content/, run the build script, and point your agent at your fork.

Is it free?
Yes. No payments, no accounts.

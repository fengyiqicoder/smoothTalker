Privacy Policy

Effective 25 September 2026

Summary

SmoothTalker collects no personal data. It has no accounts, no login, no cookies, no analytics, and no server-side code. It is a set of static files.

What SmoothTalker is

SmoothTalker is a read-only library of conversation playbooks published as static JSON files and an OpenAPI description. An AI agent (such as Muse) downloads the library and applies it locally when helping you write messages.

Data we collect

None. SmoothTalker has no way to receive data from you or your agent. All endpoints are plain HTTP GET requests for static files. There are no forms, no request bodies, no authentication tokens, no user identifiers.

Data your agent sends

The messages you ask your agent to write, and the content of messages you share with it, never leave your agent. SmoothTalker only provides the playbooks; the drafting happens inside the agent. We cannot see your conversations, contacts, or drafts.

Hosting logs

The files are hosted on GitHub Pages and a custom domain. GitHub may record standard web server logs (IP address, user agent, requested URL) for security and operational purposes under GitHub's privacy statement. We do not access, store or analyse these logs.

Cookies and tracking

None. SmoothTalker pages set no cookies and load no third-party scripts, analytics, or pixels.

Children

SmoothTalker does not collect data from anyone, including children.

Changes

If this policy changes, the new version will be published at this address with an updated effective date. The full history is visible in the public repository.
